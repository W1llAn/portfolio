# Reglas de contenido

- Única fuente de verdad: src/data/profile.ts. Ningún componente tiene texto biográfico hardcodeado.
- No inventar datos, métricas, empresas ni roles. Si falta algo, dejar `// TODO: completar` y avisar.
- Proyectos como caso de estudio: problema → solución → retos técnicos → stack → enlaces.
- Proyecto EEASA: sin código, datos reales ni capturas con información de la empresa; usar diagramas y datos ficticios.
- Textos cortos y escaneables: el reclutador decide en segundos.
